# ASCII Ring

Tek dosyalık (`index.html`) ASCII yüzük animasyonu. Bağımlılık yok, derleme yok.

## GitHub Pages ile yayınlama

1. GitHub'da yeni bir repo aç (ör. `ascii-ring`).
2. `index.html` ve `README.md` dosyalarını repoya yükle:
   ```bash
   git init
   git add .
   git commit -m "ASCII ring"
   git branch -M main
   git remote add origin https://github.com/KULLANICI_ADIN/ascii-ring.git
   git push -u origin main
   ```
3. Repo → **Settings → Pages → Build and deployment** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save.
4. Bir dakika sonra adres hazır: `https://KULLANICI_ADIN.github.io/ascii-ring/`

## Yerelde açma

`index.html` dosyasına çift tıkla.
